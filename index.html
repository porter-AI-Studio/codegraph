為什麼選用 CodeGraph？

大幅提升代理程式在複雜專案中的搜尋效率

⚡
更少 Token，更低成本
在大型專案平均減少 47%~64% Token 消耗，最高節省 40% 的單次對話費用。
🔍
全文字搜尋 (FTS5)
以 SQLite FTS5 引擎驅動，能夠瞬間在大規模代碼中精準定位對應變數或函式。
🔄
自動雙向同步
利用系統底層檔案監聽機制，在變動 2000ms 後防抖 (debounce) 自動重整索引。
📦
不需 Docker，零外部依賴
純本地二進位檔與 SQLite，不涉及外部 API 或是 Docker 虛擬化，極速部署。
🛠️
廣泛語言支援
完美支援 TypeScript, Python, Go, Rust 等 20 多種熱門語言與 14 種網頁框架路由。
🔌
主流 Agent 整合
提供 `codegraph install` MCP 伺服器，自動設定並接軌 Claude Code 等環境。
