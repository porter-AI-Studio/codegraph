Tree-sitter 技術解析

解密程式碼的骨骼與結構化提取技術

一、 什麼是 Tree-sitter？

Tree-sitter 是一款由 GitHub 於 2018 年開源的通用、高效且無依賴的增量具體語法樹 (Concrete Syntax Tree, CST) 解析器生成工具。

它起初是為 Atom 編輯器的實時代碼高亮而開發，由於其極致的高效性與平台互通性，如今已被廣泛整合至 GitHub、Neovim、Claude Code 等代碼分析核心工具中。

二、 核心特點與優勢

  • 多語言支援 (Universal)：同一套核心解析模型可以支援 C, C++, Java, JavaScript, Python, Rust, Go 等數十種程式語言。
  • 原生增量建置 (Incremental Build)：當開發者編輯並保存檔案時，Tree-sitter 僅會針對程式碼中被修改的局部的代碼區間重新計算 AST，耗時通常維持在 1~5 毫秒內。
  • 極佳的容錯性 (Error-Tolerant)：在開發期或 Agent 撰寫代碼過程中，檔案時常處於語法未完成或報錯狀態。Tree-sitter 能夠在程式碼出錯時自動執行錯誤修復，依然返回一棵「局部正確」的語法樹。
  • WASM 相容部署：底層由純 C 撰寫，可編譯為 WebAssembly (wasm) 在瀏覽器或本地輕量 Node.js 環境中高速執行。

三、 AST (抽象語法樹) 與 CST (具體語法樹) 的根本差異

在語法分析技術中，這兩大樹狀結構有著不同的關注點：

  • CST (具體語法樹 / 分析樹)：記錄源碼中 100% 的字符细节，包含所有的關鍵字、逗號、分號、括號等 Token。
  • AST (抽象語法樹)：去除了冗餘的語法修飾符，僅保留與程序邏輯和語意相關的核心結構。

Tree-sitter 實際上產生的是 CST，但它透過劃分「具名節點 (Named Nodes)」與「匿名節點 (Anonymous Nodes)」來同時提供 AST 與 CST 的能力。

節點分類 語意範例 Tree-sitter 屬性
具名節點 (Named Node) identifier (變數名稱)、number (數值) isNamed() === true (代表程式邏輯的結構骨骼)
匿名節點 (Anonymous Node) 分號 ;、關鍵字 let、圓括號 ( ) isNamed() === false (僅作為語法修飾 Token)

四、 Node.js/WASM 實戰程式碼

在 JavaScript 中使用 tree-sitter 的基本步驟如下：

const Parser = require('tree-sitter');
const JavaScript = require('tree-sitter-javascript');

// 1. 初始化 Parser
const parser = new Parser();
parser.setLanguage(JavaScript);

// 2. 進行 CST 解析
const source = 'let val = 42;';
const tree = parser.parse(source);
const root = tree.rootNode;

console.log(root.toString());
// 輸出 S-expression: (program (lexical_declaration (variable_declarator name: (identifier) value: (number))))

五、 S-Expression 模式匹配 (Pattern Matching Query)

S-Expression（符號表達式）是 Lisp 語言傳統的括號嵌套結構，Tree-sitter 借鏡了此語意來進行高性能的聲明式 AST 搜尋匹配。

例如以下聲明式 Query，可以瞬間從代碼庫中搜尋並高亮所有的「變數宣告」與「箭頭函式」：

// 匹配被指派為箭頭函式的變數
(variable_declarator 
    name: (identifier) @definition.varName
    value: (arrow_function) @definition.arrowFunc)
