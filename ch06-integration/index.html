第 6 章 · Part 3：安裝與代理程式整合

整合與配置主流 AI 代理程式

將 CodeGraph 作為 MCP 伺服器掛載到 AI 核心大腦

一、 一鍵整合指令

單純安裝 CLI 只能在本地端執行 codegraph 指令，要讓 AI 代理能夠在對話中調用它，必須將其配置為 MCP (Model Context Protocol) 伺服器。

在新開的終端機視窗中，執行以下核心整合命令： 

codegraph install

（快捷方式：若不想全域安裝 CLI，可以直接透過 npx @colbymchenry/codegraph 於下載後自動完成安裝與配置流程。）

二、 支援並自動偵測的 AI 工具清單

執行 codegraph install 時，CLI 會在背景自動掃描你當前電腦已安裝的開發軟體，並自動寫入對應的 MCP 設定檔：

  • Claude Code：Anthropic 官方終端機 Agent 工具。
  • Cursor：主流 AI 程式編輯器（Agent 模式與 @Codebase）。
  • Antigravity / Gemini CLI：本地端高效能 AI IDE 與終端代理。
  • Hermes Agent / Kiro / Codex CLI / OpenCode。

三、 底層變更與 MCP 運作原理

在執行整合後，CodeGraph 會在背景進行如下的操作。以下為 CodeGraph 作為 MCP 伺服器與 AI Agent 之間通訊的底層架構：

1. 修改設定檔

以 Claude Desktop 為例，它會自動將伺服器寫入設定檔（如 Windows 下的 %APPDATA%\Claude\claude_desktop_config.json）：

{
  "mcpServers": {
    "codegraph": {
      "command": "codegraph",
      "args": ["serve", "--mcp"]
    }
  }
}

2. 傳遞系統指令與權限

當 Agent 啟動時，它會透過 MCP 協議自動與本地的 CodeGraph 連線。CodeGraph 將作為一個常駐的後端服務（透過 codegraph serve --mcp），接收 Agent 發送的查詢，並以亞毫秒級的速度返回 SQLite 的代碼子圖數據。

📷 【預留圖檔位置 6-1：Cursor 的 MCP 設定畫面截圖】

Gemini 補圖說明：提供一張 Cursor 的 Settings ➔ Features ➔ MCP 頁面截圖，展示已成功新增一個名為 `codegraph`，Type 為 `command` 的伺服器項目。

四、 安全解除安裝 (Uninstall)

如果你不想再使用 CodeGraph，或者要重置所有的 AI 代理 MCP 配置，只需執行以下命令： 

codegraph uninstall

這會自動將 CodeGraph 的 MCP 伺服器設定、系統指令與讀寫權限從所有已配置的 Agent 中移除。

💡 備註：解除安裝命令不會刪除你專案目錄下的 .codegraph/ 索引資料庫。若要清除專案本機資料庫，請至專案根目錄下執行 codegraph uninit，或是直接手動刪除 .codegraph/ 資料夾。
