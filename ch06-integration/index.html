第 6 章 · Part 3：安裝與代理程式整合

整合與配置主流 AI 代理程式

將 CodeGraph 作為 MCP 伺服器掛載到 AI 核心大腦

一、 一鍵整合指令

單純安裝 CLI 只能在本地端執行 codegraph 指令，要讓 AI 代理能夠在對話中調用它，必須將其配置為 MCP (Model Context Protocol) 伺服器。

在新開的終端機視窗中，執行以下核心整合命令： 

codegraph install

（快捷方式：若不想全域安裝 CLI，可以直接透過 npx @colbymchenry/codegraph 於下載後自動完成安裝與配置流程。）

二、 支援並自動偵測的 AI 工具清單

執行 codegraph install 時，CLI 會在背景自動掃描你當前電腦已安裝的開發軟體，並自動寫入對應的 MCP 設定檔：

工具 / 編輯器類型MCP 設定檔位置
Claude CodeCLI Agent~/.claude.json（MCP 伺服器）；~/.claude/settings.json 只放選用的允許規則
CursorAI 編輯器Settings → Features → MCP
Gemini CLICLI Agent~/.gemini/settings.json
Antigravity本地 AI IDE自動寫入專案根目錄

三、 底層變更與 MCP 運作原理

在執行整合後，CodeGraph 會在背景進行如下的操作。以下為 CodeGraph 作為 MCP 伺服器與 AI Agent 之間通訊的底層架構：

1. 修改設定檔

以 Claude Code 為例，MCP 伺服器寫在使用者層級的 ~/.claude.json （Windows 為 C:\Users\<你的帳號>\.claude.json）的 mcpServers 底下， 官方 README 的手動設定如下：

~/.claude.json 
{
  "mcpServers": {
    "codegraph": {
      "type": "stdio",
      "command": "codegraph",
      "args": ["serve", "--mcp"],
      "alwaysLoad": true
    }
  }
}

alwaysLoad 讓 codegraph_explore 從第一個提示開始就載入； 否則 Claude Code 會把每個 MCP 工具延後到「工具搜尋」之後才載入，新 session 一開始只看得到工具名稱。 想讓所有 CodeGraph 工具免確認，可以另外在 ~/.claude/settings.json 加上這段允許規則（選用）：

~/.claude/settings.json（選用） 
{
  "permissions": {
    "allow": [
      "mcp__codegraph__*"
    ]
  }
}
ℹ️
官方支援清單裡沒有 Claude Desktop

1.x README 列出的九個支援對象是 Claude Code、Cursor、Codex CLI、opencode、Hermes Agent、Gemini CLI、 Antigravity IDE、Kiro、GitHub Copilot；codegraph install 不會自動設定 Claude Desktop。 若要在 Claude Desktop 使用，需要自行把同樣的 mcpServers 區塊寫進它的設定檔。

2. 傳遞系統指令與權限

當 Agent 啟動時，它會透過 MCP 協議自動與本地的 CodeGraph 連線。CodeGraph 將作為一個常駐的後端服務（透過 codegraph serve --mcp），接收 Agent 發送的查詢，並以亞毫秒級的速度返回 SQLite 的代碼子圖數據。

四、 安全解除安裝 (Uninstall)

如果你不想再使用 CodeGraph，或者要重置所有的 AI 代理 MCP 配置，只需執行以下命令： 

codegraph uninstall

這會自動將 CodeGraph 的 MCP 伺服器設定、系統指令與讀寫權限從所有已配置的 Agent 中移除。

ℹ️
備註：解除安裝不會刪除本機資料庫

解除安裝命令不會刪除你專案目錄下的 .codegraph/ 索引資料庫。若要清除專案本機資料庫，請至專案根目錄下執行 codegraph uninit，或是直接手動刪除 .codegraph/ 資料夾。

💡
一次安裝，多工具同步生效

codegraph install 只需執行一次，CLI 會自動掃描並同時更新所有已安裝的 AI 工具設定。若之後新安裝了其他工具（如 Cursor），重新執行 codegraph install 即可補充整合，無需手動修改設定檔。
