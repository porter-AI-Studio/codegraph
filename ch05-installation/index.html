第 5 章 · Part 3：安裝與代理程式整合

快速安裝與版本升級

跨平台一鍵化配置本地 CLI 執行環境

一、 本地端安裝條件與優勢

CodeGraph 內部捆綁了自己的 Node.js 執行期環境（Runtime），這意味著即使你的開發機上完全沒有安裝 Node.js，或者是處於特殊的版本限制下，CodeGraph 也能順暢運作，並且不會與你原本的全局 Node.js 版本產生任何衝突。

二、 跨平台安裝指令與途徑選擇

根據你目前的開發環境，請參考下方決策樹選擇最適合的安裝途徑，然後開啟終端機執行對應指令：

1. macOS / Linux (cURL 方式)

利用官方腳本下載並將二進位檔自動加入環境變數：

curl -fsSL https://raw.githubusercontent.com/colbymchenry/codegraph/main/install.sh | sh

2. Windows (PowerShell 方式)

使用管理員或一般權限開啟 PowerShell 執行以下 Web 請求指令：

irm https://raw.githubusercontent.com/colbymchenry/codegraph/main/install.ps1 | iex

3. 通用 NPM 安裝方式

如果你已經具備 Node.js 環境，亦可透過 NPM 進行全域安裝：

npm i -g @colbymchenry/codegraph

⚠️ 重要提醒：安裝腳本將 codegraph 指令添加至你的 PATH 環境變數中，但它不會立刻更新你當前已開啟的終端機視窗。請在安裝後重新開啟一個新的終端機視窗，指令才能被成功解析。

三、 CLI 版本升級與管理

CodeGraph 提供了高度自動化的內建升級器，它會智慧辨識你當初的安裝途徑（Bundle 腳本、NPM 或 npx），並執行原地更新：

1. 自動檢查與升級

直接執行以下指令進行在線更新：

codegraph upgrade

2. 僅檢查是否有新版本

加上 --check 參數，僅輸出版本對照，不執行寫入：

codegraph upgrade --check

3. 鎖定並安裝特定版本

若需要回滾或鎖定特定的發行版本：

codegraph upgrade 0.9.4
