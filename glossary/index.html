名詞解釋 (Glossary)

解讀本書中使用的關鍵術語，建立統一的詞彙認知。

一、核心名詞釋義

1. Tree-sitter WASM (Tree-sitter 增量語法樹解析器)

定義：一種能將原始碼解析為抽象語法樹 (AST) 的工具，透過 WebAssembly (WASM) 打包以支援跨平台執行。

解析器特性與優勢：
相比於沉重的 LSP，它具有語法容錯性強、部署極簡與增量速度極快的特點。即使程式碼有語法錯誤也能成功解析，為 AI Agent 提供了低延遲且穩定的程式碼結構來源。

架構策略：

  • 增量處理：依賴其增量解析能力處理頻繁的程式碼變更 (Cmd+S)，僅重算受影響的子樹。
  • 效能優先：專注於結構關係而非 100% 的類型推斷，在效能與準確度之間取得最適合 Agent 的平衡。

2. SQLite / codegraph.db (本地圖資料庫)

定義：CodeGraph 專用的本地端儲存引擎，用於存放解析後的節點 (nodes)、邊界 (edges) 與 FTS5 檢索資料。

輕量化儲存設計：
捨棄了重量級的 Neo4j 或向量資料庫，直接將全域依賴關係落盤至輕量級的 SQLite 中，實現亞毫秒級的查詢與寫入。它確保了 AI Agent 能在極低延遲下取得代碼地圖。

資料管理策略：

  • 100% 本地化：利用本地 SQLite 徹底解決隱私與外部連線延遲問題。
  • 圖資料關聯化：將複雜的圖演算法查詢轉化為高效的 SQL JOIN 操作，兼具圖分析能力與關聯式資料庫的穩定性。

3. S-Expression Query (S-Expression 查詢語法)

定義：一種 Tree-sitter 提供的宣告式查詢語言，用於從龐大的語法樹中精準匹配特定的程式碼特徵。

精準萃取機制：
CodeGraph 不直接將整棵冗餘的語法樹丟進資料庫或餵給 AI Agent，而是利用 S-Expression 模式匹配，篩選出類別、方法、函式定義或路由等關鍵符號。

索引最佳化策略：

  • 語言擴展：透過撰寫自訂的 Query Patterns 來快速支援新語言的語法解析。
  • 降噪處理：僅抽取對 AI Agent 有價值的結構關係，大幅減少圖資料庫的儲存體積與上下文雜訊。

4. Code RAG (代碼探索檢索)

定義：一種專為代碼庫設計的檢索增強生成架構，依賴於語法樹解析與明確的引用關係（精確幾何），而非模糊的語義相似度。

架構差異與優勢：
傳統的 Document RAG 使用向量檢索，可能因為變數名稱在語意上相近而產生錯誤的匹配（例如將 verifyUser 與 validateToken 混淆）。Code RAG 則仰賴 AST 靜態解析出的調用圖加上 SQLite FTS5，提供 100% 確定的符號路徑。

實踐策略：

  • 精確優先：放棄向量檢索（Vector Search），以精準的圖譜遍歷 (DFS/BFS) 作為主導技術來發現依賴。

5. Working Memory (Agent 工作記憶)

定義：AI Agent 在處理任務過程中，用來暫存上下文與專案結構理解的短期記憶空間（即 Context Window）。

記憶負載問題：
面對陌生的大型專案時，Agent 往往需要透過數十次的 grep 與讀取檔案，才能在工作記憶中拼湊出脆弱的靜態結構圖。這種「盲人摸象」的探索流程會消耗大量 Token 與時間。

優化策略：

  • 記憶卸載：透過 CodeGraph 提供預先算好的全域關係地圖，讓 Agent 能夠一次性獲取精確的調用鏈，大幅減輕其工作記憶的負擔。

二、名詞特徵對照表

術語 主要症狀 / 表象 影響 推薦策略
Tree-sitter WASM 將程式碼即時解析為 AST，支援跨平台與語法容錯 大幅降低 AI 理解程式碼結構的延遲與環境配置成本 捨棄部分精確度換取增量效能與穩定性
SQLite / codegraph.db 將結構資料落盤為關聯式與全文檢索表 免去部署複雜圖資料庫，保證 100% 本地隱私與亞毫秒級查詢 利用 SQL JOIN 替代部分圖遍歷查詢
S-Expression Query 從龐大語法樹中模式匹配出關鍵符號 去蕪存菁，避免圖資料庫或 AI 上下文被無關緊要的語法細節淹沒 針對不同語言撰寫精確的萃取 Patterns
Code RAG 基於語法樹解析與引用關係進行檢索 解決了傳統向量檢索在代碼場景中精確度不足的問題 專注於精確的圖譜遍歷，放棄基於相似度的向量推測
Working Memory Agent 執行任務時的短期記憶空間 大量的盲目探索會迅速耗盡 Token 並導致記憶混亂 利用外部知識圖譜提供完整結構，減少 Agent 自身記憶負載
